# Lovable Website Prompts: Hack for RVA Public-Facing Site

**Purpose:** Build a minimal, compelling public-facing website to share what we're doing and why  
**Event:** Hack for RVA - March 6-8, 2026 at CoStar Headquarters  
**Target Audience:** Richmond technologists, entrepreneurs, students, community members

---

## 🎯 Website Strategy Overview

### Goals
1. **Inspire action**: Get people excited to participate
2. **Explain clearly**: What is this event and why does it matter?
3. **Lower barriers**: Make it feel accessible, not intimidating
4. **Build trust**: Show this is real, backed by Mayor + CoStar + RVA Tech
5. **Capture interest**: Email list signup for when registration opens

### Core Message
*"Richmond's future should be built by Richmonders. Join us to engineer the city we want to live in."*

### Design Philosophy
- **Minimal and modern**: Clean, not cluttered
- **Mobile-first**: Most people will browse on phones
- **Accessible**: High contrast, readable fonts, simple navigation
- **Richmond-branded**: Local pride, not generic tech event
- **Action-oriented**: Every section drives toward email signup

## 🎨 Design System Notes for Implementation

### Color Palette Suggestions
- **Primary**: Navy blue (#1A365D) - represents professionalism, trust, government
- **Accent**: Bright teal or cyan (#00B4D8) - energy, innovation, tech
- **Secondary**: Warm orange (#FB8500) - community, action, warmth
- **Neutral**: Grays for text and backgrounds
- **Success**: Green for checkmarks and confirmations

### Typography
- **Headings**: Bold, modern sans-serif (Inter, Poppins, or Work Sans)
- **Body**: Readable sans-serif (Inter, Open Sans, or system fonts)
- **Sizes**: Use a type scale (16px base, 1.25 ratio)

### Spacing
- Use consistent spacing: 8px, 16px, 24px, 32px, 48px, 64px
- Generous white space to avoid feeling cramped

### Icons
- Use a consistent icon set (Lucide, Heroicons, or Feather Icons)
- Line icons, not filled (more modern and minimal)
- Consistent stroke width

## 📱 Mobile-First Considerations

### Critical Mobile Views
1. **Hero**: Stack headline, subheadline, CTA vertically
2. **Stats**: Single column with large numbers
3. **Challenge cards**: Full-width cards, scrollable
4. **Form**: Single column, large touch targets
5. **Navigation**: Hamburger menu

### Touch Interactions
- Minimum 44px touch targets
- No hover-dependent interactions
- Swipeable elements where appropriate

## 📝 Notes for Using These Prompts with Lovable

### Best Practices
1. **Start with Prompt 1** and build incrementally
2. **Test mobile view** after each major prompt
3. **Adjust copy** as needed—these are starting points
4. **Add real content** when available (logos, images, exact dates)
5. **Iterate**: Lovable allows quick iterations—refine based on what you see
6. **Keep it simple**: Don't over-engineer. A clean, fast site beats a feature-heavy slow one.

### Prompt Tips for Lovable
- Be specific about layout and spacing
- Reference modern design patterns ("like [example site]")
- Ask for mobile-first responsive design explicitly
- Specify animation subtlety (avoid overwhelming effects)
- Request accessibility features upfront
- Ask for component-based structure for easy updates

### Order of Operations
1. Run Prompts 1-3 to establish foundation (hero, about, opportunity)
2. Review and adjust styling before proceeding
3. Run Prompts 4-7 for core content (format, challenges, differentiators, audience)
4. Run Prompts 8-9 for social proof and inclusion (partners, diversity)
5. Run Prompt 10 for main CTA (email signup)
6. Run Prompts 11-12 for FAQ and footer
7. Run Prompt 13 for final polish
8. Test everything on mobile and desktop
9. Gather feedback and iterate
