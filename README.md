# Richmond Civic Hackathon - Knowledge Base

**Building Richmond's Premier Civic Innovation Event**

> *"Let's engineer the city we want to live in."*

---

## 🎯 Mission

Bring Richmond's technologists together to build solutions for a thriving economy. Focused on **Mayor Avula's Pillar 4: A Thriving Economy**, this hackathon connects Richmond's funders, community connectors, and builders to solve economic development challenges. This knowledge base contains everything needed to plan, execute, and sustain the Richmond Civic Hackathon as a 10-year civic innovation ritual.
