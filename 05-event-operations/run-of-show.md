## 🚨 Decision Points & Contingencies

### Real-Time Decisions

**Who Makes Calls:**
- **Minor logistics:** Crystal (operations lead)
- **Technical issues:** Nick (tech lead)
- **Sponsor concerns:** Tom/Alex
- **Major problems:** Ford (final authority)
- **Safety/emergency:** Ford + CoStar security

### Common Scenarios

**Scenario: WiFi Fails**
- Tech team activates backup (mobile hotspots)
- Announce to participants
- Extend timeline if needed

**Scenario: Food Runs Out**
- Emergency food delivery (budget contingency)
- Order pizza/delivery
- Crystal approves emergency spend

**Scenario: Team Conflict**
- Operations lead mediates
- Separate teams if needed
- Code of Conduct enforcer involved if serious

**Scenario: Medical Emergency**
- Call 911 if serious
- Notify CoStar security
- Use first aid if minor
- Contact emergency contact
- Document incident

**Scenario: Code of Conduct Violation**
- Staff member takes report
- Consult with Ford/Crystal immediately
- Follow Code of Conduct enforcement procedures
- Remove offender if necessary
- Support victim

**Scenario: Weather Emergency (Friday)**
- Monitor weather closely
- Delay start if necessary
- Communicate via email/Discord
- Have backup Saturday-only plan
