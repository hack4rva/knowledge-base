# Venue Planning

CoStar headquarters venue-specific planning, requirements, and coordination.

---

## 🏢 Venue Information

**Location:** CoStar Group Headquarters, Richmond, VA

**Capacity:** 150-200 participants (Year 1 target)

**Expected Employee Count:** 3,000+ at full build-out

---

## 📋 Venue Features

### Available Spaces
- Auditorium
- Conference rooms
- Green roof terraces
- Amphitheater (publicly accessible)
- Open collaboration spaces

### Included Amenities
- High-quality A/V equipment
- Professional security
- Cleaning/janitorial services
- Basic WiFi (NOTE: Must supplement with high-density solution)
- LEED/Energy Star certified facilities

---

## ✅ Venue Requirements Checklist

### Capacity Confirmation
- [ ] Confirm max capacity with Claire at CoStar
- [ ] Determine optimal space configuration
- [ ] Plan for 150-200 participants + 20-30 staff/mentors/judges

### Accessibility
- [ ] Verify ADA-compliant entrances
- [ ] Confirm elevator access to all event spaces
- [ ] Identify gender-neutral restrooms
- [ ] Plan accessible seating and workspaces
- [ ] Test wayfinding and signage needs

### Technology Infrastructure
- [ ] Test existing WiFi capacity
- [ ] Contract specialized high-density WiFi vendor ($5,000 budget)
- [ ] Verify power outlet distribution (1 strip per table minimum)
- [ ] Test A/V equipment in presentation space
- [ ] Plan backup internet solution

### Security & Access
- [ ] Coordinate with CoStar security team
- [ ] Plan pre-registration and check-in process
- [ ] Design badge/wristband system
- [ ] Establish emergency evacuation procedures
- [ ] Create visitor access protocols

### Food Service Areas
- [ ] Identify meal service/buffet areas
- [ ] Confirm kitchen access for catering
- [ ] Plan trash/recycling stations
- [ ] Set up beverage/snack stations throughout venue

### Parking & Transportation
- [ ] Understand parking availability and cost
- [ ] Communicate public transit options (subsidies offered to CoStar employees)
- [ ] Consider shuttle service if needed
- [ ] Provide clear arrival instructions
