## Document Creation Guidelines

When creating missing documents:

1. **Use Existing READMEs as Foundation**
   - Many READMEs contain comprehensive content
   - New documents can be extracted sections or deeper dives

2. **Follow Markdown Standards**
   - Clear title (# heading)
   - Purpose/overview section
   - Table of contents for long docs
   - "Last Updated" date at bottom

3. **Cross-Reference Liberally**
   - Link to related documents
   - Reference main README and START-HERE
   - Cite sources (especially MLH guidance)

4. **Include "To Do" Sections**
   - List remaining work for the document
   - Help future editors know what's incomplete

5. **Add to Parent README**
   - Update directory README when creating new docs
   - Brief description of what it contains
