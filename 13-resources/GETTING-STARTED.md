## ✍️ Adding Information

### When You Create Something New

1. **Find the Right Directory**
   - Use the Table of Contents in main README
   - Go to the most relevant numbered directory

2. **Create the Document**
   - Use markdown format (.md)
   - Follow naming conventions (lowercase-with-dashes.md)
   - Include a clear title and purpose at the top

3. **Update the Directory README**
   - Add your document to the directory's README
   - Briefly describe what it contains

4. **Update Main README If Needed**
   - If it's a major new section, add to main Table of Contents

### Document Formatting Guidelines

**Every document should have:**
- Clear title (# heading)
- Brief purpose/overview
- Table of contents for long docs
- Consistent markdown formatting
- Last updated date at bottom

**Use markdown features:**
- `#` for headings (H1 through H6)
- `-` or `*` for bullet lists
- `1.` for numbered lists
- `**bold**` for emphasis
- Tables for structured data
- Code blocks for examples
