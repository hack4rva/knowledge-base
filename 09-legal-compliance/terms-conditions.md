## 10. Project Submissions

### 10.1 Submission Requirements

To be eligible for judging and prizes:
- Project must be submitted by deadline (Saturday 10:00 PM)
- Must include working demo or prototype
- Must include code repository with LICENSE file
- All team members must sign IP Declaration Form
- Must comply with all rules and policies

### 10.2 Originality

Projects must be:
- Created substantially during the Event (Friday-Saturday)
- Original work by the team
- Not plagiarized or copied
- Properly attributed if using open source libraries

**Pre-existing code is allowed** if clearly documented, but majority of work must be new.

### 10.3 Disqualification

Projects may be disqualified for:
- Violating Code of Conduct
- Not using open source license (for civic challenges)
- Plagiarism or IP infringement
- Violating third-party terms of service
- Missing submission deadline
- Incomplete submissions
